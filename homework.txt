'number'+3+3 // number33 - если хотя бы один операнд строка, то + превращает всё в строку и делает конкантенацию, (-, *, /) - наоборот пытаются привести всё к числам

null + 3 // 3 - оператор + с нестроковыми  типами пытается привести оба операнда к числам, null в числовом контексте становися 0

5 && "qwerty" // "qwerty" - оператор && возвращает одно из значений операндов, если левый операнд Falsy То && возвращает его, если левый оператор Truthy то && возвращает правый операнд. В нашем случае число 5 это Truthy, не Truthy это - (0, "", null, undefined, NaN, false)
