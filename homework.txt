'number'+3+3 // number33 строка - если хотя бы один операнд строка, то + превращает всё в строку и делает конкантенацию, (-, *, /) - наоборот пытаются привести всё к числам

null + 3 // 3 число - оператор + с нестроковыми  типами пытается привести оба операнда к числам, null в числовом контексте становися 0

5 && "qwerty" // "qwerty" - оператор && возвращает одно из значений операндов, если левый операнд Falsy То && возвращает его, если левый оператор Truthy то && возвращает правый операнд. В нашем случае число 5 это Truthy, не Truthy это - (0, "", null, undefined, NaN, false)

+'40' + +'2' + "hillel"; // 42hillel стринг - + В начале строки пытается преобразовать строку в число, тоесть у нас 40 + 2 = 42, когда один операнд строка, оператор + превращает всё в строку (конкатенация).

'10' - 5 === 6; // false - Оператор - всегда приводит операнды к числам, в отличие от +. === - строгое сравнение, оно сравнивает и тип и значение. получается 5 - 6 поэтому False.

true + false // 1 - при выполнении арифметических операций JS приводит булевыве значения к числам: true - 1, false - 0, поэтому 1+0 = 1

'4px' - 3 // NaN - Оператор - всегда пытается привести оба операнда к числам. Но строка "4px" не может быть полностью преобразована в число — в ней есть буквы, поэтому мы получаем Not a number. NaN - 3 = NaN - Любая операция с NaN даёт NaN.

'4' - 3 // 1 число - Оператор - всегда приводит оба операнда к числам.

'6' + 3 ** 0; // 61 стринг - Оператор ** — это возведение в степень. 3 ** 0 = 1 так как любое число в степени 0 = 1. поэтому получаем '6' + 1 = '61', Оператор + со строкой приводит второй операнд к строке → происходит конкатенация

12 / '6' // 2 число - так как / приводит всё к числам

'10' + (5 === 6); // 10false стринг - так как 5 не равно 6 получаем false, + привращет это всё в строку

null == '' // false - так как  == не строгое сравнение, кот делает приведение типов по спец правилам. но для Null есть исключения: Null при нестрогом сравнении равен только двум значениям, Null, undefined и не преобразуется к числу или строке, поэтому мы получаем false

3 ** (9 / 3); // 27 число - сначала выполняется деление в скобках, потом возведение в степень (9/3) = 3, 3**3 = 27

!!'false' == !!'true' // true - 'false' — строка, не пустая → truthy,  'true' — тоже строка, не пустая → truthy. Оператор ! преобразует значение в boolean и инвертирует: !'false' → false, !!'false' → true, !'true' → false, !!'true' → true, значит у нас true == truе. 

0 || '0' && 1 // 1 число - && имеет выше приоритет, чем ||. Оператор && возвращает первое ложное значение или последнее истинное, если всё истинно.
'0' — это truthy, 1 — тоже truthy. Значит результат: 1. Оператор || возвращает первое истинное значение. 0 - ложное а 1 - истинное, значит мы получаем 1

(+null == false) < 1; // false - Унарный плюс + пытается привести значение к числу. значит +null = 0, при сравнении == разных типов JS приводит false как 0, значит 0 == 0 есть тру.   При сравнении < JS приводит булевы значения к числу: true = 1, значит 1 < 1  есть false

false && true || true // true - сначала вычесляем && false является falsy, значит false || true, Оператор || возвращает первое truthy значение. Значит будет true

false && (false || true); // false - Делаем то что в скобках, первое truthy значение это true значит у нас остается false && true, Оператор && возвращает первое falsy значение или последнее truthy, первый операто False является falsy. 

(+null == false) < 1 ** 5; // false - +Null значит 0 далее 0 == false приводятся типы 0 == 0 - true, теперь возводим в степень 1 ** 5  - 1, сравнение true < 1,  Булевы значения при числовом сравнении приводятся к числу, значит 1 < 1 - false
